## Consequence for the product rollout

Count ArtCraft-X as a separately named, experimental and license-blocked product; count AniCraft as a named but empty planned product. Neither is an appropriate first host for end-to-end validation. Craft Status is a developer operations utility; crafthub and craft-contrib are not creative hosts. ArtCraft Services is the backend dependency / documented API boundary for ArtCraft, with a different license from the Apache-2.0 desktop repository.

An “all products supported” roadmap must preserve those distinctions. It must not infer an app called WinCraft from `winprint.rs` (a forked Windows printing library) or `winit` (a forked windowing library).
